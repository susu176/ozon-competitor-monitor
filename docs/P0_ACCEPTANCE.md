# P0 云端验收报告

日期：2026-10-16（北京时间）。验收原始版本：`13f5266`，分支 `feat/p0-monitor-foundation`。本次范围仅模拟采集与基础设施，不接 Seerfar、不调用收费 API、不访问真实店铺、不发送飞书消息，不修改其他仓库。

## 结论

原始版本不能整体通过验收：虽然原有 7 项测试全部通过，但 Actions 每次创建临时数据库，无跨运行历史；首次基线仍列出全量首次发现与类目；失败响应附带的商品也可能产生首次发现提醒。本轮修正上述行为，新增 Git 数据分支持久化与针对性测试。**修正后的云端功能/真实远端 Git 持久化通过；实际 Actions 权限与定时执行未完成验证，P0 不作全项通过结论。真实 Ozon 监控可用性未验证。**

## 原版本未通过及处理

1. 首次基线全量商品仍进入首次发现及类目列表：已改为基线无商品变化提醒，并补零值断言。
2. 失败 payload 可能触发新发现并污染后续已见集合：已屏蔽失败记录的提醒和历史已见集合，并测试下一次成功采集仍能发现商品。
3. 原版仅统计完整三级路径，缺少逐级汇总：已补一级至三级统计与父级路径隔离测试。
4. 原 Actions 每次新建 `/tmp/ozon-demo.sqlite3`：已换成先恢复数据分支、校验历史、采集、提交推送的流程，缺失/损坏不得自动重新建基线。

## 未完成与限制

- **实际 GitHub Actions 权限与运行记录**：读取 `actions/permissions`、列出运行记录均返回 `Forbidden`。本轮 Git 通道写入成功不证明 GITHUB_TOKEN 或分支规则允许 runner 写入；也未证明 Actions 对本仓库已启用。
- **实际定时任务**：未提供真实 runner 成功日志。工作流尚在功能分支；schedule 仅运行默认分支中的工作流，且 GitHub 可能延迟执行。不能保证 09:00 准时完成日报。
- **人工调度与连续运行**：需具备 Actions API 权限后触发工作流并检查至少两次运行中恢复的历史日期与行数。本轮云端三目录验证不冒充真实跨日 Actions 运行。
- **失败同日更正**：当前保留每日不可变快照；同日失败/部分采集后成功采集会因内容不同拒绝覆盖，安全失败而非误报。后续需要多运行版本与更正策略。
- **长期灾备**：分支持久化已实现，独立灾备与 Git 历史容量控制未实现。不可通过删库重建解决恢复故障。
- **真实 Ozon 采集、字段来源真实性、分页覆盖、稳定性及访问许可**：未验证，等待 3～5 家店铺链接后进入 P1 小样本验证。
- **实际飞书推送**：按要求不配置 Webhook；仅模拟消息，不代表网络发送、分段、业务错误处理和发送去重已完成。
